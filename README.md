# 🧮 Calculator Web App

A simple and responsive calculator web application built using HTML, CSS, and JavaScript.  
This project performs basic arithmetic operations like addition, subtraction, multiplication, and division.

## ✨ Features

- ✅ Basic arithmetic operations (+, −, ×, ÷)
- ✅ Responsive design
- ✅ Clean and modern UI
- ✅ Keyboard input support (optional if added)
- ✅ Error handling for invalid operations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## 📖 How It Works

- User clicks number buttons
- Operation is selected
- Result is calculated using JavaScript logic
- Output is displayed instantly on the screen
